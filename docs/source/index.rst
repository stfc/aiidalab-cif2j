AiiDAlab CIF2J Documentation
============================

Welcome to the AiiDAlab CIF2J documentation. This app provides a UI for the
`aiida-cif2j <https://github.com/stfc/aiida-cif2j>`_ plugin's ``WannierTB2JWorkChain``,
which computes magnetic exchange interactions from a CIF/MCIF structure via a Quantum
ESPRESSO + Wannier90 + TB2J pipeline. For the underlying AiiDA plugin itself, see
`aiida-cif2j <https://github.com/stfc/aiida-cif2j>`_\.
